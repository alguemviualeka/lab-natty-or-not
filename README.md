# Podcast: Anamauê Kids - Episódio 01 - Chico Science 🎙️

## 📒 Descrição
Este podcast de 3 minutos oferece um passeio rápido pelo universo do maracatu, cultura percussiva com raiz em Pernambuco. No primeiro episódio, é falado um pouco sobre a figura de Chico Science, músico icônico de Recife e responsável pela criação do movimento Manguebeat.

## 🤖 Tecnologias Utilizadas
- IA Generativa **[ChatGPT](https://chat.openai.com)** para roteirização e revisão;
- IA Generativa **[ElevenLabs](https://www.elevenlabs.io)** para clonagem e sintetização de voz;
- Software **[Audacity](https://www.audacityteam.org/)** para edição e montagem do podcast.

## 🧐 Processo de Criação
"ChatGPT" foi utilizado para desenvolver o roteiro e aprimorar a narrativa do podcast. "ElevenLabs" ajudou a criar uma voz sintética envolvente para a narração, enquanto o "Audacity" foi essencial para a edição final, garantindo um fluxo suave e profissional.

## 🚀 Resultados
O episódio é uma introdução acessível e estimulante ao mundo da cultura do maracatu, ideal para quem busca uma compreensão rápida do assunto.
